
Project Background / Proposal: 
The basis of my project lies within one of the classes I had taken this semester, Stress Management. I wanted to create a way for students and/or users to manage the specific academia or career-oriented tasks of their lives through a system that would leave Sunday (hence why the calendar is designed as MON-SAT) as a day to manage leisure. Users with a connection to the application will be able to register accounts, interact, and log into a web-based application that they can use to add/delete/update their activities throughout the week. The application also demonstrates the usage of relational MySQL databases in the world of user utility. Connected the frontend from a current project of mine.
